    ANNIE Data and MC Samples¶

    Where to find ANNIE's production data and simulation samples, which ones to use, and how to ask for new ones.

    New to ANNIE data?

    Start with Getting started and the technote Preparing Data for Analysis (DocDB 6699).

    Recommended samples¶

    If you need Use Status
    Beam data to develop an analysis Gen 1 2% unblinded subset Recommended
    Beam data for a final analysis Gen 1 ProcessedData and BeamClusterTrees (blinded) Recommended
    Neutrino interactions in the tank Gen 1 MC central value: tank Recommended
    Neutrino interactions in the whole geometry Gen 1 MC central value: world Recommended
    MC with untilted PMTs (detector variation) Untilted PMTs Available
    The newest processing Gen 2 data In production

    How this site is organised¶

    • Samples are grouped by generation: one consistent processing of the data, plus the MC meant to be compared with it.
      • Generation 1: FY22–FY25 data event-built with EBV2. This is the data in the current publications and theses.
      • Generation 2: reprocessing with ToolAnalysis V1.6.0, starting with FY25.
    • Every sample has a status label. The labels are explained in Getting started.
    • Samples are given as dCache paths. SAM definitions will be added later.
    • Superseded samples are on the Deprecated page, with the reason for each.

    Requesting a sample¶

    Requests are GitHub issues made from a form: open a request. The forms and what happens next are described on Requesting a sample.
