# Generation 2: Data

<span class="badge production">In production</span>

Generation 2 reprocesses the data with
[ANNIEsoft/ToolAnalysis V1.6.0](https://github.com/ANNIEsoft/ToolAnalysis/releases/tag/V1.6.0), with the
updated event building described in *Decoder stage* (Anuj Gupta,
[DocDB 7006](https://annie-docdb.fnal.gov/cgi-bin/sso/ShowDocument?docid=7006)). FY25 is being processed
first. FY22–FY24, FY26 and FY27 (being taken now) will follow, and there will be a Generation 2 2%
unblinded subset.

!!! danger "Blinded data"
    Generation 2 beam data is **blinded**. Please contact the analysis coordinators, Jingbo Wang and Andy
    Mastbaum, before accessing it, and follow the [blinding scheme](../getting-started.md#blinding).
